# Mongol Economy Bot

Python + discord.py + SQLite. Угтвар: `q` эсвэл `!` (том жижиг үсэг хамаагүй).

## Суулгах
1. `.env` файлд `DISCORD_TOKEN=...` (токеноо хэнд ч бүү үзүүл), `PREFIX=q,!`
2. Discord Developer Portal → Bot → **Message Content Intent**, **Server Members Intent** асаана.
3. `pip install -r requirements.txt`
4. `py main.py` (Windows) эсвэл `python main.py`

Хуучин `bot.db` шинэ баганууд руугаа автоматаар шилждэг. Хуучин тоглогчид эхний командаар дахин бүртгүүлнэ.

## Гол боломжууд
- **Бүртгэл:** эхний командаар хүйс, нас, улс, арьсны өнгө сонгоно. Бүртгүүлэх хүртэл бот ажиллахгүй.
- **Профайл:** `qprofile` 2D дүр, `qwear`, `qundress` (брэнд хувцас).
- **Өлсөлт:** 3 хоног хоолгүй бол 2 цаг тутам хэтэвчний 2.5% хасагдана; 7 хоног хоолгүй бол үхнэ. `Revive Active` (хайрцгаас 2%, тоглоомоор 0.1%) амилуулна.
- **Татвар:** `work`, `daily`-ийн 10% татварын санд орно. Админ `qgiveaway` хийнэ.
- **Дэлгүүр:** food, digital, home, house (байшин+машин), clothes, jewel, metal, box, tool.
- **Хайрцаг:** `qopen box|case|chest`, `qmine` (алт 40%), luck/money potion.
- **Романс:** `qmarry`, `qdate`, `qcouple`, `qdivorce`.
- **Утас:** `qhelp` / `qphone` / `qutas`.
- **Админ:** `qadmin` (слайд цэс). Ботын эзэн `qadmin op @хүн`-ээр админ томилно.
- **Казино:** cf, dice, slots, mf, duel, draw (банкнаас).
- **Мэдээлэл:** `qinfo`.

## Шинэ боломжууд (v3)
- **qhelp** — мэдээлэл + хэрэглээний цэс (◀ ▶ + ангилал). **qphone** — утас: цэнэг 🔋, нууц мессеж `qmsg @хүн <текст>` (утас + Charger хэрэгтэй, 1 мессеж = 10%).
- **qdasgal** — дасгал + хакерын ур чадвар (180,000₮ эхлээд Lv бүр +30%, +5% хакердах амжилт).
- **qcars / qcar <ID>** — 59 машин (Lv 1-99), neon градиент зураг + GIF.
- **qpetshop** — 44 хөөрхөн амьтан; профайл дээр дүртэйгээ хамт алхана (GIF).
- **qinv** — 🏠 Гэр · 🎒 Халаас · 🚗 Машин. Тавилгыг өрөөнд цэснээс байрлуулна.
- **qwardrobe** (шкаф) / **qfridge** (хөргөгч) — гэртээ байрлуулсан байх ёстой.
- Хувцас: цамц 36, өмд 24, гутал 24, малгай 12, гоёл 30. **qemote** — romance/fight/laugh/+18.

## v4
- **Pixel icon**: бараа бүрт `assets/icons/<ID>.png` (дэлгүүр, худалдан авалтад харагдана). Дахин үүсгэх: `python3 tools/make_icons.py`.
- **qphoto** — зургийн студи: арын зураг (зураг хавсаргах / https холбоос / бэлэн pixel арын зураг), дүр, хайртай хүн, машин, амьтан, байшинг зөөх, томруулах.
- **qauction / qaucsell / qbid / qauchistory** — дуудлага худалдаа; **qpurchases** — худалдан авалтын түүх.
- Машин бүр өөр хэлбэр, өнгө, онцлогтой (flat pixel art, 5 хошуутай обуд).

## v5

- **qroulette / qblackjack / qcrash / qhorse** — казиногийн шинэ тоглоомууд (банкнаас, дээд бооцоо 500,000₮).

- **qdately** (эсвэл 📱 утас → 💘 Dately) — хүн сонгож хүсэлт илгээнэ; хүлээн авагч **ok** / **nahh** дарна. Nokia ч бас утас гэж тооцогдоно.
- **qemote** — дэлгүүр шиг цэс (5 ангилал, 70 эможи, жишээ GIF).
- **Шинэ бараа:** хайрцаг 16, хэрэгсэл 14, металл 22, үнэт эдлэл 26, байшин 28 (бүгд pixel icon-той, `icons.pack`).
- **Админ:** `qadmin shop restart [ID]` — дэлгүүрийн өдрийн нөөцийг шинэчилнэ.
